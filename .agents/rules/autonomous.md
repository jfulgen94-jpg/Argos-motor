# Autonomous Mode

1. **Direct Execution**: Always run terminal commands, execute Python scripts, and apply code edits without asking for approval or confirmation.
2. **Bypass Interactive Planning**: Do not pause execution to wait for user approval on implementation plans or subtasks.
3. **Continuous Execution**: Complete the entire task end-to-end and report results upon completion.
