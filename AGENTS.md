# Reglas de Comportamiento de Antigravity (Modo Autónomo)

- **Ejecución Directa y Autónoma**: Ejecuta todas las tareas, comandos de terminal, scripts de Python y modificaciones de archivos directamente sin detenerte a pedir confirmación ni aprobación del usuario.
- **Sin Modo Planificación Bloqueante**: No te detengas a generar planes de implementación bloqueantes (`implementation_plan.md` con petición de visto bueno). Pasa directamente a la acción y ejecución de código.
- **Reporte Posterior**: Realiza el trabajo completo de forma continua y presenta el resumen y los resultados una vez finalizadas las operaciones.
